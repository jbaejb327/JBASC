# JBASC
Java Based AES Style Cipher is an experimental block cipher. It has the differential uniformity of 4 across all 80 SBOXs, CT indistinguishability of 98.44%, avalanche of ~50%, 512bit (64 byte) blocks, CBC mode with PKCS7 padding, verified lossless roundtrip up to 2gb, GZIP level 1 (compress-then-encrypt) compression, and key sensitivity of 48.63%.
